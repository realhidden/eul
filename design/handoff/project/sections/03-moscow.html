Feature map — MoSCoW

Scoped to be shippable by a small community team in months. Subtraction is listed with the same care as addition — the deleted features are design decisions, not regressions.

Must — v2.0 does not ship without these

Anchor + strip bar modelThe notch answer; the reason 2.0 exists (§2.2–2.3).
Priority collapse + width governorSlots drop by user priority before macOS hides anything; numeric width reservation ends bar jitter for good.
Health engineThresholds + hysteresis + culprit attribution; turns density into hierarchy — the answer to "nothing tells me what to care about."
The panelReplaces the dropdown; investigation in ≤2 interactions; keeps the open-only collector contract.
Per-core CPU, E/P labeledThe data exists and is a top ask; lives in the CPU tile's expanded state, not the bar.
History sparklines (CPU · GPU · MEM · NET)10-minute in-memory ring buffers answer "what just happened?" new data
Recovery flowOcclusion detection, the one notification, relaunch-opens-panel, global hotkey (§2.5).
Settings rebuild — 3 panesGeneral / Menu Bar / Health. Replaces configuration sprawl with decisions (§4.4).
Semantic token palette, dark + lightOne palette, both modes, color-blind-safe load colors (§5).
Honest App Store buildFewer monitors, never error states: no thermal/fan rows exist, health engine runs on remaining signals, one settings footnote explains builds.
i18n hardening23 languages incl. RTL; no text in graphics; 1.5× expansion budgeted in every layout; numerals tabular everywhere.

Should — in v2.0 if the schedule holds

Widgets, rebuilt: 2 not 4Small "health" + medium "trends," with honest staleness stamps (§6). Configurability moves to 2.x.
Fan control — Auto / Manual / BoostThe TG Pro wedge: temperatures and control in one free, quiet tool. Fenced by P6: helper installed only at the moment of intent (§4.6), absent on fanless Macs and in the App Store build. First should-have cut if the schedule slips — the revamp does not depend on it. new infra
Bluetooth battery tileAirPods L/R/case granularity — data already collected, promoted from dropdown footnote to a panel tile.
Process app iconsNSRunningApplication icons make the process list legible at a glance; cheap, high-value garnish.
Uptime + load averagesIn the CPU tile's expanded state; near-zero cost, long-tail ask.

Could — v2.x candidates, designed-for but not built

Widget configurabilityChoose-your-monitors via WidgetKit intents new infra 14+.
Sensors surfaceThe 60+ named Apple Silicon temperature sensors as a power-user panel section.
CSV exportRing buffers → file, for the measurement-minded minority new infra.
Network identity monitorsPublic/local IP, SSID, Rosetta indicator — SSID requires Location permission, so it must remain opt-in new data uncertain feasibility.
Disk I/O sparklineOnly if a disk-activity tile earns its place new data.
Fan curves / smart coolingTemperature-triggered automation is technically possible but interventionist-by-default — it ships only after a release of manual control has earned trust. v2.x at most.
Panel pop-outPin the panel as a floating window for sustained monitoring sessions; explicitly not the primary surface.

Won't — declined, quotably

Weather, per-process GPU, iPad companionUpstream decisions stand: out of scope, root-requiring, or out of category. (Fan control, formerly on this list, enters scope by maintainer override — see Should.)
Per-monitor text-component orderingDeleted. Slots have one strong layout; priority order is the only knob (P5).
Font design pickerDeleted. One type system, tabular by law (§5.1).
Per-monitor refresh ratesDeleted. One global cadence (1–10 s); the panel may exceed it while open.
The four legacy static widgetsDeleted, replaced by the two honest ones (§6).
The focus-stealing "status bar hidden" alertDeleted, replaced by the recovery flow (§2.5).
