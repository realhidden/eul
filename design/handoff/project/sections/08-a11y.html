Accessibility

A data-dense bar is only dense visually — semantically it is one sentence.

8.1 VoiceOver

The anchor is a single button whose label is the verdict plus the headline figures: "eul — all systems normal. CPU 12 percent, network down 2.4 megabytes per second." The strip's slots are not separate stops — the anchor speaks for the bar, so a VoiceOver pass over the menu bar costs one stop, not five. State changes are not announced unprompted (P3 applies to audio too). Inside the panel: tiles are grouped elements ("CPU, 47 percent, 62 degrees, elevated — expanded, 12 cores"), process rows read name-then-value, and sparklines expose Audio Graph descriptions new infra 14+.

8.2 Reduce Motion & Transparency

Reduce Motion removes all panel motion: the two structural animations (open, expand) and the panel's value-update motion — number rolls, bar / per-core / sparkline tweens, and text cross-dissolves — so every value snaps at the refresh cadence instead. The bar and widgets never animate regardless. Reduce Transparency swaps the popover material for an opaque equivalent; tokens are defined against both. All value-update motion is panel-only and gated on this setting (§5.5), so the degraded experience is simply the calm, snapping one.

8.3 Color vision

Elevated/amber and critical/red are separated by lightness, paired with shape (one eye fills vs. both), and never read against green. Memory/disk segments use opacity, not hue. Verified against deuteranopia and protanopia simulation as a release gate, not a hope.

8.4 Text scaling

macOS has no Dynamic Type, so eul defines its own two steps: default and Large (≈1.15×), following the system's menu-bar size where the OS exposes it. Slots re-reserve worst-case widths per step — stability law survives scaling. The panel grows vertically, never horizontally, and may scroll the process list only.
